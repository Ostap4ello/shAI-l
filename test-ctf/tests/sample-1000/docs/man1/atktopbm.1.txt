NAME
     atktopbm - convert Andrew Toolkit raster object to PBM


SYNOPSIS
     atktopbm [atkfile]


DESCRIPTION
     This program is part of Netpbm(1).

     atktopbm  reads  an  Andrew Toolkit raster object as input.  and produces a
     PBM image as output.
