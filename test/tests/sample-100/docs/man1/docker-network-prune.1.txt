NAME
     docker-network-prune - Remove all unused networks



SYNOPSIS
     docker network prune [OPTIONS]



DESCRIPTION
     Remove all unused networks



OPTIONS
     --filter=      Provide filter values (e.g. "until=")


     -f, --force[=false]      Do not prompt for confirmation



SEE ALSO
     docker-network(1)
